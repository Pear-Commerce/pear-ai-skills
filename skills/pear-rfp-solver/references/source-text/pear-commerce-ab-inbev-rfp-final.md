We’ve created some special product features to help alcohol brands navigate the regulation.
Set a minimum retailer requirement.
Brands have the ability to set a minimum retailer requirement by geo during set-up, allowing brands to leverage dynamic inventory feeds that drive to in-stock retailers.
What happens when a certain geo doesn’t meet the minimum requirement?
Set up a contingency plan so the platform automatically pulls in additional retailer options (hard coded) to ensure compliance.
Differentiate retailers vs. marketplaces.
Brands can indicate whether or not they want marketplaces to count towards the minimum retailer requirement.
Optionally, use a setting to only display marketplaces when the retailer minimum is not met, so there is still a path to purchase
Uniquely Designed for Alcbev

How do these compliance- based settings come to life?
Let’s say you’re running a national campaign for Cutwater. The majority of people who click the ad and arrive at a landing page will see a list of multiple retailers with available local inventory that they can choose from, like the example here.

But in some geos, the requirement to show at least 3 retailers is not met. So in those instances, Pear can set up the campaign to automatically do one of three things (depending on ABI preference).

Show no retailers. While this is not an ideal scenario, it will ensure compliance with state regulation in geos where minimums cannot be met.

Option 2.
If the minimum number of retailers isn’t met, Pear can then bypass inventory scanning to always show additional selected retailers until the minimum is met.

Display marketplaces only so there is still a path to purchase available. This is possible because Pear’s platform can differentiate between a retailer and a marketplace.
