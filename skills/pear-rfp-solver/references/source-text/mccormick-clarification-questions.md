How IP tracking works:
When a shopper loads a Pear experience (store locator, shoppable PDP, landing page, or in-ad Pear
Connect), our event pipeline creates a single page-load record. That record currently includes an ip
field along with derived geo (city/state/ZIP), device, UTM, retailer, SKU, and conversion timestamps.
What it is used for:
- Session quality & fraud controls (bot filtering, duplicate session heuristics).
- Geolocation fallback (deriving city/state/ZIP if a user hasn’t given location permission).
- Attribution hygiene (deduping unusual traffic bursts from single network egress points).
What it is not used for:
- Not shared to ad platforms or used to build audiences. Pixels & audience building use click events
only itself, not ip address.
- Not used to identify named individuals.
- Not used to enrich PII.
- Not used to train any third-party AI model
